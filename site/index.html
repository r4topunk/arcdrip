ArcDrip

A shared USDC stream for collectives on Arc: one rate, N shares, live runway. A pre-funded pool pays USDC per second, split among members by mutable integer shares. Joining, leaving or re-weighting mid-stream is one O(1) write that touches nobody else.

Scaffold page. The full project page (guarantees, addresses, proof transactions, comparison table) is written in a later build phase. Source: github.com/r4topunk/arcdrip.
